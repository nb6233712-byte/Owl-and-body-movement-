Revised filing fees for the 2026 season

The current ladder sits under the market at every rung — a $200 floor against a $281 benchmark for a plain 1040, and an 1120-S at $750 against $1,123. This draft resets all six tiers and the add-ons.

It also moves every price into one data file. Today the same numbers are written out by hand on the homepage, File Taxes and Business — three copies that will eventually disagree with each other in front of a client.

How it's built

  • pricing.jsonSource of truth. Every price, tier, feature and add-on. The only file anyone edits.
  • build-pricing.mjsNode 18+, zero dependencies. Regenerates the partials and prints a change report.
  • pricing.cssStyles for the generated markup. Class prefix .pat-, no collisions.
  • partials/pricing-individual.htmlGenerated. 1040 tiers.
  • partials/pricing-business.htmlGenerated. Entity return tiers.
  • partials/pricing-addons.htmlGenerated. Add-on table, footnote, bookkeeping offer.

edit pricing.json  →  run node build-pricing.mjs  →  commit partials/
never hand-edit anything in partials/ — the next build overwrites it

For the developer

  • Include the partials server-side or at build time, not by client-side fetch. Pricing is search-relevant content on a tax site — it needs to be in the served HTML, not assembled in the browser.
  • All CTAs are generated from one constant. CTA at the top of build-pricing.mjs currently points at file-room.html. Repoint it once to swap every button — for example to Stripe Payment Links, so a published price can actually be paid.
  • Set --pat-font on .pat-pricing if the module shouldn't inherit the page typeface. Everything else themes off the seven variables at the top of pricing.css.
  • The bookkeeping discount is now capped at $600. Uncapped, 50% off a $1,150 business return gives away $575, and grows with every future increase. The cap lives in conversionOffer.
  • Strip the old numbers everywhere. Grep the repo for $200, $350, $450, $550, $750 and $1,250 before shipping — including meta descriptions, JSON-LD and any alt text.
